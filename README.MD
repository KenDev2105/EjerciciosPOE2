# Manual de Usuario
Ejercicios de la segunda clase de POE
-------------------------------------------
## 1 - Clonar Repositorio
Primero vamos a clonar el repositorio en local
`git clone https://github.com/KenDev2105/EjerciciosPOE2`
## 2 - Navegacion 
Nos movemos a la carpeta del repositorio
`cd EjeciciosPOE2`

## 3 - Ejecuccion
Para correr el codigo, hay un script de bash ya creado. Simplemente lo ejecutamos
`./`
